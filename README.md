# Working Board 🧩

A full-stack Kanban board application with JWT-based authentication. Built with:

- **React + TypeScript** (Frontend)
- **Node.js + Express + TypeScript** (Backend)
- **PostgreSQL** with Sequelize ORM
- **JWT Authentication**

---

## ✨ Features

- User login and logout
- Secure token storage via `localStorage`
- Protected routes based on login state
- Create, view, and delete Kanban tickets
- Ticket statuses: Todo, In Progress, Done
- Minimal, responsive UI

## USAGE
- Navigate to /login to enter your credentials.

- On successful login, your token is stored in localStorage.

- View and manage your tickets on the main / board page.

- Click "Logout" to remove your token and end the session.
